# 知喻工具箱（astrbot_plugin_zhiyu_toolbox）

知喻（小鱼妹妹）的多功能工具箱：**运行状态查询、发言清洗、发送节流、群聊总闸**。
全部功能不走斜杠命令：管理员直接在聊天里发口令，插件硬校验身份后执行；
配置项也能在 AstrBot 面板「插件管理 → 知喻工具箱」里改，两边改完立即生效并落盘，重启不丢。

插件还自带 **WebUI 视图「工具箱控制台」**：AstrBot 面板 → 插件管理 → 知喻工具箱 → 视图，进去可以直接看实时状态、开关群聊总闸、修改全部配置，不用发口令也能管。

## 一、聊天口令一览（仅管理员；非管理员发了一律静默忽略）

| 口令 | 作用 |
| --- | --- |
| 查状态 / 查下状态 / 看看状态 / 运行状态 / 状态卡 / 跑了多久 / 用了多少token / 装了几个插件 / 有没有报错 / 限流次数 / 哪个模型最费 / 现在用的是哪个模型 等 | 直接发「SL/AS 状态 + 今日 token 用量」卡片：版本、平台、运行时长、群/私聊次数与均句消耗、总用量、LLM 调用数、缓存命中率、限流次数、rpm；卡片为 Pillow 本地绘制的图片版田字格 |
| 群聊上限4 | 全局每分钟插话硬上限改为 4 条（范围 1~999），立即生效 |
| 查看群聊上限 / 群聊上限多少 | 报当前插话上限与统计窗口 |
| 聊天间隔10-20 | 单群插话间隔改为 10~20 秒随机；只写一个数就是固定间隔；两个数自动小的在前 |
| 查看聊天间隔 / 聊天间隔多少 | 报当前单群间隔区间 |
| 关闭聊天间隔 / 聊天间隔关闭 | 关闭单群间隔（间隔置 0，只受全局上限约束） |
| 关闭群聊 | 群聊总闸关闭：所有群静默，不再回复任何群消息 |
| 开启群聊 / 打开群聊 | 群聊总闸恢复，群聊照常 |

提示：总闸关闭期间，「开启群聊」等管理口令仍有效（口令入口优先级高于总闸）；
但「查状态」这类要发卡片的功能在群里会被总闸一起拦下；私聊不受影响。

## 二、功能说明

### 1. 运行状态查询
- 命中问法且是管理员 → 直接发状态卡片并终止事件：不进模型、不写会话历史、不进记忆库、不耗字数。
- 数据全部来自本机文件与本地数据库，不联网、不输出密钥/地址/路径。
- 非管理员命中问法 → 静默不理。
- 状态卡默认用 Pillow 本地绘制成田字格图片：黑底白字、左右框线像素级对齐，不调模型、不耗 token；渲染或发送失败自动回退纯文本卡片。
- 面板 delivery 可选「直接发卡片（推荐）」或「交给知喻用自己的话说」。
- 通用版自带 Noto 中文字体（插件 fonts/ 目录），Linux/Windows 都能直接出图片卡；缺 Pillow 时自动回退文本卡。依赖见 requirements.txt（Pillow、psutil）。

### 2. 发言清洗（消息发出前的最后一道）
- 删占位词：整条只是「（安静旁听，不回复）」这类占位 → 不发送
- 主动拒答：模型输出 <refuse/> 标签且没有实质内容 → 整条不发送（配合人格卡沉默机制）
- 删自造标签：模型偶尔给回复自包 <reply> 之类的标记 → 开/闭、半截都删掉，不进 QQ 也不进会话历史
- 删自定义词：在面板/控制台「额外要删的词/标签」里自己加词或标记（英文逗号/换行分隔），命中直接从回复里删掉
- 删括号/星号动作神态、半截括号、表情包 &&分类标签
- 删复述与拼贴：照抄对方原话、整段搬别人或自己刚说过的话 → 删掉或整条不发
- 合并空行、限行数、压波浪号、剥句尾句号、限长（优先按完整句子断）、过短不发
- 90 秒内重复同一句 → 不发送
- 词表与阈值全部可在面板调整；打开 clean_verbose_log 可在日志看每次清洗动作

### 3. 发送节流（防刷屏双保险，只管「插话」，被@回复不计数永远放行）
- 全局硬上限：所有群+私聊插话共享一个 60 秒滑动窗口，最多 send_rate_max 条，超出直接丢弃（不排队不补发）
- 单群随机间隔：同一个群两次插话至少隔 group_gap_min~group_gap_max 秒的随机值，节奏不机械
- send_message_to_user 框架旁路直发同样计入同一账本（源码级补丁），没有绕过限流的通道
- 每分钟限制与单群间隔各有独立总开关（send_rate_enabled / group_gap_enabled），可只留一层
- 两层同时生效；被丢弃会记日志（插话超速丢弃 / 单群间隔未到丢弃）

### 4. 群聊总闸
- 「关闭群聊」写入 flag 文件，所有群消息在入口直接终止（优先级高于状态卡与陪伴插件）
- 「开启群聊」删除 flag 恢复；私聊永远不受影响

## 三、权限与安全
- 管理员名单：面板 admin_ids 填了用它；留空自动跟随主配置 admins_id
- allow_group 默认关：管理工具只在私聊生效；打开后管理员在群里也能用（结果全群可见）
- 身份按真实 QQ 号硬校验，模型说了不算；非管理员拿不到数据，也触发不了任何管理口令

## 四、安装与更新

- AstrBot 面板 → 插件管理 → 安装插件 → 从 GitHub 安装，填本仓库地址即可；也可手动下载 zip 解压到 AstrBot 的 `plugins/` 目录后重启
- 首次安装会自动按 requirements.txt 安装依赖（Pillow、psutil）
- 更新版本同样走面板「检查更新」，或重新下载 zip 覆盖后重启
